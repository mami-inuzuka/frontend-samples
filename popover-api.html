Popover API のサンプル

popover 属性 / popovertarget 属性 / top layer の挙動を体感するデモ

1. 基本: popover="auto"

最小コード。HTML 属性だけで開閉・Esc・外側クリックでの自動クローズが動く。

Sample
これが popover の中身
外側クリック / Esc キーで閉じる
同時に 1 つしか開けない（auto モード）。Esc キーでも閉じる。
実装イメージ
<!-- popovertarget で対応付けるだけ -->
<button popovertarget="my-popover">開く</button>

<div id="my-popover" popover>
  これが popover の中身
</div>

/* JS は一切不要 */
2. auto vs manual

popover 属性のモードによって閉じ方が変わる。manual は自前で閉じない限り開いたまま。

Sample
popover="auto"
外側クリックや Esc で自動で閉じる。
別の auto を開くとこっちは閉じる。
popover="manual"
外側クリックや Esc では閉じない。
「閉じる」ボタンで自前で hide が必要。
両方開いて、外側クリック・Esc キーを試してみてください。manual だけ残ります。
実装イメージ
/* auto: ブラウザが面倒見てくれる */
<div popover="auto">...</div>

/* manual: 自前で開閉する */
<div id="m" popover="manual">...</div>

<script>
  const el = document.getElementById("m");
  el.showPopover();   // 開く
  el.hidePopover();   // 閉じる
  el.togglePopover(); // トグル
</script>
3. top layer の威力

祖先に overflow: hidden や transform があっても、popover は top layer に出るため clip されない。

Sample
❌ 通常の position: absolute
overflow: hidden + transform
これは普通の div。
祖先の overflow: hidden で
clip されてしまう。
✅ Popover API (top layer)
overflow: hidden + transform
top layer に出るので
祖先の overflow を
貫通して表示される！
両方とも「overflow: hidden + transform」の枠の中にあります。左は枠で切られてしまいますが、右は枠を貫通して全体が表示されます。
DevTools で popover 要素を選択 → Elements の </html> 直前に #top-layer が出現するのが確認できます。
実装イメージ
<!-- 祖先に overflow:hidden があっても -->
<div style="overflow: hidden;
            transform: translateZ(0);">

  <button popovertarget="p">開く</button>

  <!-- DOM はこの中にあるけど -->
  <!-- 描画は top layer に飛ぶ -->
  <div id="p" popover>
    clip されない！
  </div>

</div>
