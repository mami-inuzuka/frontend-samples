CSS Anchor Positioning のサンプル

anchor-name でアンカーを定義し、anchor() で別の要素から位置を参照する

⚠️ このページは Anchor Positioning（Baseline 2026-01）を使用しています。最新の Chrome / Edge / Safari / Firefox で動作します。古いブラウザでは正しく表示されません。

1. 基本: アンカーに張り付ける

兄弟関係（親子ではない）の 2 要素で、片方を anchor-name で名指しできるアンカーにし、もう片方が anchor() で位置を参照する。

Sample
🟠 div（follower）
ボタンの位置は Flexbox の justify-content を切り替えているだけ。follower は anchor() で自動的に追従する。
実装イメージ
/* HTML: 兄弟関係 (親子ではない) */
<div class="stage" data-align="center">
  <button class="anchor">ボタン</button>
  <div class="follower">div</div>
</div>

/* ① Flexbox でボタンの位置を制御 */
.stage {
  display: flex;
}
.stage[data-align="left"]   { justify-content: flex-start; }
.stage[data-align="center"] { justify-content: center; }
.stage[data-align="right"]  { justify-content: flex-end; }

/* ② ボタン側: アンカーに名前を付ける */
.anchor {
  anchor-name: --my-anchor;
}

/* ③ div 側: anchor() で位置を参照 */
/* position: absolute なので flex の影響を受けない */
.follower {
  position: absolute;
  top:  anchor(--my-anchor bottom);
  left: anchor(--my-anchor left);
}

/* JS は data-align 属性を書き換えるだけ */
2. ずらし方の組み合わせ

anchor() 単体だとピタリ張り付くだけ。calc() で間隔を足し、transform: translate() で中央寄せを足すと「ボタンの真下、12px 離して中央配置」が作れる。

Sample
🟠 div（follower）
「素朴」だと div の左端がボタンの中央に来てしまう。translateX(-50%) で自分の幅の半分左にずらして中央揃え。
実装イメージ
/* 素朴: anchor() だけ */
.follower {
  position: absolute;
  top:  anchor(--my-anchor bottom);
  left: anchor(--my-anchor center);
  /* ← div の左端が center に来てしまう */
}

/* 完成形: calc + transform */
.follower {
  position: absolute;
  /* (1) 12px 下に離す */
  top:  calc(anchor(--my-anchor bottom) + 12px);
  left: anchor(--my-anchor center);
  /* (2) 自分の幅の半分だけ左に */
  transform: translateX(-50%);
}
お使いのブラウザは Anchor Positioning に対応していないようです。Chrome / Edge / Safari / Firefox の最新版でご覧ください。
